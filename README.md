# Nishant Bakshi: portfolio

A single page portfolio. Open it at https://nishantkbakshi.github.io/Nishant-Portfolio/

What is on it:

- **Product for India.** A predictive maintenance idea for home appliances. A 96 second narrated video, a live simulated motor that predicts and classifies faults, and a business case with a calculator.
- **Workforce planning.** A machine learning forecast of the next two hours of work by area, and how many people each area needs.
- **Predictive maintenance.** An engine health classifier at Rolls-Royce and a vehicle health classifier at Ford, plus a failure predictor you can train in the browser.
- **StagON.** An animation of how early drone detection buys time.

All demos run in the browser on simulated data. Nothing here is real company data.
